# Programação_Linear

Junção de testes e algoritmos usados na disciplina de Programação Linear. Usado a biblioteca HiGHS para python.

### Observações:
Os dois print's foram os problemas usados para os algoritmos. Os problemas possuem variações, como por exemplo, demanda fixa e variável.
Repertório possui códigos de teste, alguns tirados da documentação do [HiGHS](https://highs.dev/) e outros feitos por mim.
